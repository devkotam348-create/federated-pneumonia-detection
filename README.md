# federated-pneumonia-detection
## Description 
find the if there is pneumonia or not by comparing the x-ray
## Problem/Motivation
Patient data is highly sensitive, and privacy concerns make it difficult 
for hospitals to share data with each other. Federated Learning solves this 
by training a shared model without any hospital's raw data ever leaving their own servers.
## Tech Stack
- Python
- NumPy
- Pandas
- Pytorch
- CNN/ResNet
- FedAvg
- matplotlib
- Streamlit

## Project Status
🚧 work on progress
## Dataset
This project uses the [Chest X-Ray Pneumonia dataset](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia) by Paul Mooney, available on Kaggle.
It contains chest X-ray images labeled as NORMAL or PNEUMONIA, split into training, testing, and validation sets.
